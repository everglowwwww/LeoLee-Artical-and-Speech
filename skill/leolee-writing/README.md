# LeoLee Writing Skill

基于 LeoLee 实际论文和演讲稿分析提炼的个人写作规范 skill。

## 安装

```bash
# 使用 Codex skill-installer
python scripts/install-skill-from-github.py --url https://github.com/everglowwwww/LeoLee-Artical-and-Speech/tree/main/skill/leolee-writing

# 或手动复制到 ~/.codex/skills/leolee-writing/
```

## 功能

- **论文写作**：按 LeoLee 的格式规范（字体/字号/行距/边距）生成 .docx 论文
- **演讲稿写作**：基于 PPT 逐页撰写学术演讲稿（整合 speaker 工作流）

## 格式规范

| 参数 | 标准值 |
|---|---|
| 正文字体 | 宋体 10.5pt (5号) |
| 英文/数字 | Times New Roman 10.5pt |
| 标题字体 | 华文中宋 18pt |
| 行距 | 固定值 17pt |
| 页边距 | L/R 3.17cm, T/B 2.54cm |
| 首行缩进 | 21pt |
